# Contributing to the affiliate programs directory

Thanks for improving the list. Contributions should be factual, readable, and easy to verify.

## Add a program

1. Search the README **and open pull requests** for the program name and official domain to avoid duplicates.
2. Check the program's official affiliate page or terms. Include the source URL and the date checked in your PR description.
3. Add a single row to the existing five-column comparison table: number, linked program name, commission structure, attribution/cookie window, and application link.
4. Explain whether a commission is one-time, limited to a number of months, or recurring while a referral is active. Write **Not publicly stated** when a term cannot be verified; do not guess.
5. Use the next available number *after accounting for open PRs*. Recheck numbering right before merging, since other contributors might also append rows.
6. If the final number changes, update every affected program-count reference in README (intro, editorial note, comparison description, and FAQ).
7. Disclose if you own, work for, or represent the program.

Keep the commission cell concise. Put complex eligibility, payment, and payout exceptions in the PR description or link to the official terms rather than turning a comparison cell into a paragraph.

## Corrections and removals

Open an issue or PR with the existing program name, exact correction or removal reason, the official source link, and the date checked. Do not silently delete or reorder unrelated rows.

## Review guidelines

- Program inclusion is not endorsement, ranking, or guaranteed placement.
- The first two entries are maintained in their existing positions; new rows go at the end.
- A valid website alone does not verify an affiliate offer; prefer published terms.
- Avoid promotional superlatives, guaranteed earning claims, and unverifiable cookie/payout values.
- Maintainers may request changes or decline a submission that cannot be independently evaluated.
- Do not update the editorial verification date unless an actual editorial review was performed.

**Before merging:** confirm no duplicated program/domain, unique sequential row numbers, accurate count references, and no unintended changes outside the listing.
